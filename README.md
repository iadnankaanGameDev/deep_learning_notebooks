# Deep Learning Notebooks

This repository contains my deep learning practice notebooks built with TensorFlow and Keras.

The notebooks follow a learning path from TensorFlow fundamentals to neural networks, computer vision, transfer learning, natural language processing, and time series forecasting.

## Repository Structure

- `tensorflow_fundamentals/`  
  Basic TensorFlow operations and core concepts.

- `neural_networks/`  
  Neural network regression and classification notebooks.

- `computer_vision/`  
  Image classification and computer vision experiments.

- `transfer_learning/`  
  Feature extraction, fine-tuning, and scaling up with pretrained models.

- `nlp/`  
  Text classification and NLP projects with TensorFlow.

- `time_series/`  
  Time series forecasting experiments.

- `helper_functions.py`  
  Utility functions used across notebooks.

## Topics Covered
